# The Rice Exchange. Osaka. 18th Century

Text-based game "The Rice Exchange. Osaka. 18th Century" by Yuri Pavlenko, a.k.a. Goraph, translated by Nikita Tseykovets.

The game is in English, developed for URQ_DOS, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/#rice_exchange_en). See the original Russian version [here](https://github.com/urqw/rice_exchange).

The game was first published on May 3, 2025.

Interactive fiction identifier (IFID) of the game: 99FE621A-A066-405A-B09A-A405604980D9

## Description

Japan, 18th Century. An old merchant lies dying in his home. He has three sons, and he calls them to his side: "The one among you who returns with the largest sum of money in 30 days will become my heir and receive all 10,000 yen from me as inheritance."
